# Manual Book PCC-110

## Operator
1. Login sebagai operator.
2. Pilih Input Laporan.
3. Isi lokasi, jenis, prioritas, W1, dan deskripsi.
4. Generate tiket.
5. Klik Kirim WhatsApp atau Salin Pesan.
6. Pantau antrean pada Riwayat Laporan.

## Pamapta
1. Buka link token dari WhatsApp.
2. Periksa detail laporan.
3. Tekan Berangkat.
4. Tekan Tiba di TKP.
5. Isi hasil penanganan.
6. Upload minimal 1 dan maksimal 5 foto.
7. Isi tanda tangan jika diperlukan.
8. Tekan Selesai.

## Pimpinan
1. Login sebagai pimpinan.
2. Dashboard menampilkan KPI hari ini.
3. Grafik diperbarui otomatis setiap 15 detik.
4. Export CSV tersedia langsung.
5. Export PDF membutuhkan Dompdf.

## Catatan
Tidak ada nama anggota atau nama regu nyata pada aplikasi. Akun dan laporan seed adalah data dummy.
